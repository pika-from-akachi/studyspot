# 产品章程 — StudySpot

## 1) 产品定位

StudySpot 是一个为大学生提供的校园空间与学生福祉导航平台。我们帮助学生在需要专注学习、放松恢复、社交连接或运动释放时，快速找到适合的校园空间，并连接认证的校园活动与支持资源。通过降低信息门槛和减少寻找成本，StudySpot 让健康的校园生活方式变得更容易获得，同时帮助学校更好地理解和优化空间资源配置。

## 2) 品牌关键词

- **可靠（Reliable）** — 提供准确的实时空间状态和开放时间，让学生能够信任平台给出的信息并做出有效决策
- **平静（Calm）** — 界面设计简洁清晰，不制造焦虑，帮助学生在压力时刻快速找到需要的支持而非感到更加困扰
- **连接（Connected）** — 不仅连接学生与空间，更连接学生与同伴、活动和校园支持网络，降低孤立感
- **包容（Inclusive）** — 充分考虑不同需求，包括安静与社交、室内与户外、无障碍设施、免费与预约空间的平衡
- **活力（Energetic）** — 鼓励积极的校园生活方式，让运动、社交和探索校园变得有吸引力和容易参与

## 3) 核心问题 / JTBD

当大学生需要找到适合当前需求的校园空间时——无论是为了专注学习、放松恢复、与他人交流还是运动释放——他们面临信息分散、实时状态不明、不熟悉校园资源、缺乏活动参与渠道等困扰。新生和国际学生尤其难以快速融入校园生活，而长期的空间寻找挫败感和社交孤立可能影响学习效果和整体福祉。如果没有StudySpot，学生只能依赖碎片化的信息源、过时的地图、或者反复试错，浪费时间和精力，也可能错过许多有益的校园资源和社交机会。

## 4) 目标与使命

- **使命：** 让每一位大学生在需要适合的空间、活动或支持时，都能轻松找到并连接到校园资源，从而减少信息障碍，增强归属感，支持更健康、更有活力的校园生活。

- **期望成果（描述性）：**
  - 学生能够在3分钟内找到符合当前需求的可用空间，而不是花费15-30分钟反复尝试
  - 新生和国际学生更快融入校园，减少因不熟悉环境带来的孤立感和焦虑
  - 更多学生参与健康的校园活动（运动、社交、社团），而非因为信息不足而错过机会
  - 校园空间利用率提升，闲置或被忽视的优质空间得到更充分使用
  - 学校管理者获得基于真实使用数据的洞察,优化空间配置和服务安排
  - 平台成为低门槛的校园支持基础设施，而非心理治疗工具——明确边界，连接而非替代专业服务
  - 保护学生隐私、内容安全、无障碍可用性和脆弱用户的特殊需求，这些是不可妥协的底线

## 5) 我们提供的解决方案

### 空间导航与实时状态

- **解决的问题：** 学生不知道附近有哪些适合当前需求的空间，也不清楚这些空间此刻是否可用
- **典型路径：** 学生选择当前需求类型（专注、恢复、连接、运动），查看附近空间列表及其实时拥挤程度、噪声水平、开放时间和步行距离，选择合适空间并使用二维码签到
- **用户获得的结果：** 快速找到可用且适合的空间,节省寻找时间,避免白跑和反复试错
- **边界：** 我们不提供室内精确导航，不使用摄像头或情绪识别技术，不替代学校现有预约系统而是与之连接
- **指导原则：** 隐私优先 / 准确性 / 简洁高效
- **参考：** 空间分类标准、环境标签体系、状态计算逻辑

### 认证活动与社区连接

- **解决的问题：** 学生想参与校园活动或找到有共同兴趣的同伴，但信息分散在多个平台，缺乏可信度筛选和便捷报名渠道
- **典型路径：** 学生浏览学校认证的社团活动和小组，查看活动时间、地点、人数和组织者信息，报名参加或创建新的活动小组（需实名认证），活动结束后可以评价和反馈
- **用户获得的结果：** 降低社交和活动参与门槛，更容易找到社交机会和支持同伴，减少孤立感
- **边界：** 不提供匿名论坛或私密社交功能，所有组织者需学校邮箱认证，活动有人数上限和举报机制，不替代紧急心理支持热线
- **指导原则：** 安全第一 / 实名认证 / 内容治理
- **参考：** 社区安全规范、举报与审核流程、组织者认证标准

### 个性化推荐与收藏

- **解决的问题：** 每次使用都需要重新搜索和筛选，无法记住常用空间或获得个性化建议
- **典型路径：** 系统根据学生的使用历史、收藏偏好和当前时间段，推荐适合的空间和活动，学生可以一键访问收藏列表或查看"常去空间"的当前状态
- **用户获得的结果：** 更快速便捷的重复使用体验，发现更多符合个人偏好的校园资源
- **边界：** 不构建心理健康画像或情绪预测模型，推荐仅基于空间使用行为和明确的用户偏好设置
- **指导原则：** 透明性 / 用户控制 / 隐私保护

### 校园支持资源连接

- **解决的问题：** 学生在需要学业、心理健康、职业或生活支持时，不清楚学校有哪些资源或如何获取帮助
- **典型路径：** 平台提供学校官方认证的支持资源目录（咨询中心、学业辅导、职业服务、紧急支持热线等），学生可以查看服务描述、联系方式和开放时间，一键跳转到官方预约系统或拨打支持热线
- **用户获得的结果：** 更容易找到和连接到需要的专业支持，降低求助门槛
- **边界：** 我们不诊断、不治疗、不替代心理咨询和紧急干预，仅作为信息连接层，所有专业服务由学校官方提供
- **指导原则：** 非医疗化 / 去污名化 / 清晰边界
- **参考：** 支持资源目录标准、紧急情况响应协议、隐私与保密政策

### 数据洞察与空间优化（面向学校管理者）

- **解决的问题：** 学校缺乏真实的空间使用数据，难以科学决策空间配置、开放时间和服务安排
- **典型路径：** 管理员登录后台查看匿名化的空间使用趋势、高峰时段分析、学生需求分布、设施评价等数据报告，用于指导空间改造、资源调配和政策制定
- **用户获得的结果：** 学校能够基于数据优化校园空间和服务，学生间接受益于更合理的资源配置
- **边界：** 所有数据严格匿名化和聚合处理，不追踪个人行为轨迹，不出售学生数据给第三方
- **指导原则：** 数据安全 / 匿名化 / 仅用于改进服务
- **参考：** 数据隐私政策、GDPR/个人信息保护合规标准
